    О справке

    Интерактивная справка по панели управления DC2 гребного тренажёра Dante (прошивка 0.6.10). Экраны сняты с реального устройства, описания элементов составлены по исходному коду прошивки. Файл автономный: откройте его в любом браузере.

    Полное руководство: Руководство_пользователя_DC2.md. Памятка на одну страницу: Быстрый_старт.pdf.
