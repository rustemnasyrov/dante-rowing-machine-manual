# Инструменты генерации документации

Скрипты, которыми были получены скриншоты экранов и собрана интерактивная справка.
Запускались из отдельного Python‑окружения (python 3.14) с пакетами:
`imageio-ffmpeg`, `opencv-python-headless`, `numpy`, `pillow`, `mlx-whisper` (для расшифровки звука на Apple Silicon).

| Файл | Назначение |
|---|---|
| `transcribe.py` | Расшифровка звуковых дорожек видео (`audio/*.wav` → `transcripts/*.txt`). ffmpeg должен быть в PATH |
| `extract_screen.py` | Поиск четырёхугольника экрана на кадре и выравнивание перспективы в 600×1024 |
| `build_screens.py` | Извлечение кадров из основного видео по таймкодам (`names`) и сборка `final_screens/*.jpg` |
| `normalize.py` | Выравнивание всех скриншотов по линии строки состояния (единая геометрия) |
| `hotspots.json` | Разметка экранов: зоны (в координатах 600×1024), описания, переходы (`go`), номера выносок (`num`), таймкоды видео (`t`) |
| `tours.json` | Пошаговые сценарии для интерактивной справки |
| `annotate.py` | Отрисовка зон для проверки и пронумерованной иллюстрации `images/annotated/active_workout.jpg` |
| `help_template.html` + `build_help.py` | Сборка автономного файла `dist/Интерактивная_справка.html` (картинки встраиваются в base64) |
| `build_manual_pdf.py` | Markdown руководства → HTML (pandoc) → PDF (headless Chrome); затем PyMuPDF добавляет колонтитулы с номерами страниц, оглавление с номерами страниц (два прохода) и закладки. Результат — `dist/Руководство_пользователя_DC2.pdf` |
| `build_dist.py` | Сборка всей папки `dist/`: памятка с встроенными картинками и её PDF, интерактивная справка, PDF руководства |

Чтобы изменить описание зоны или добавить экран: правьте `hotspots.json` и запустите `build_help.py`. Скрипты сборки (`build_help.py`, `build_manual_pdf.py`, `build_dist.py`, `crop_ui.py`) находят файлы относительно своего расположения; скрипты извлечения кадров содержат абсолютные пути, поправьте под своё окружение.

PDF памятки и руководства печатаются headless Chrome (путь к нему можно переопределить переменной окружения `CHROME`). Для `build_manual_pdf.py` нужны также `pandoc` и пакет `pymupdf`.

## crop_ui.py

Вырезает элементы интерфейса из `images/screens/*.jpg` по координатам (как в `hotspots.json`) и собирает наборные картинки с подписями в `images/ui/`. Запуск из папки `doc`: `python3 tools/crop_ui.py` (нужен только Pillow).

## extract_photo.py

Вырезает экраны из фотографий `media/IMG_*.jpg`: грубая оценка по чёрной рамке корпуса, затем точный поиск четырёх границ экрана по перепаду яркости и перспективное выравнивание в 600×1024. Из фото получены main, fast_start, fast_start_splits, program_create, race_setup, history, athlete, connections, wifi_connected, hrm, options.
