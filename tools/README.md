# Инструменты генерации документации

Скрипты, которыми были получены скриншоты экранов и собрана интерактивная справка.
Запускались из отдельного Python‑окружения (python 3.14) с пакетами:
`imageio-ffmpeg`, `opencv-python-headless`, `numpy`, `pillow`, `mlx-whisper` (для расшифровки звука на Apple Silicon).

| Файл | Назначение |
|---|---|
| `transcribe.py` | Расшифровка звуковых дорожек видео (`audio/*.wav` → `transcripts/*.txt`). ffmpeg должен быть в PATH |
| `extract_screen.py` | Поиск четырёхугольника экрана на кадре и выравнивание перспективы в 600×1024 |
| `build_screens.py` | Извлечение кадров из основного видео по таймкодам (`names`) и сборка `final_screens/*.jpg` |
| `normalize.py` | Выравнивание всех скриншотов по линии строки состояния (единая геометрия) |
| `hotspots.json` | Разметка экранов: зоны (в координатах 600×1024), описания, переходы (`go`), номера выносок (`num`), таймкоды видео (`t`) |
| `tours.json` | Пошаговые сценарии для интерактивной справки |
| `annotate.py` | Отрисовка зон для проверки и пронумерованной иллюстрации `images/annotated/active_workout.jpg` |
| `help_template.html` + `build_help.py` | Сборка автономного файла `Интерактивная_справка.html` (картинки встраиваются в base64) |

Чтобы изменить описание зоны или добавить экран: правьте `hotspots.json` и запустите `build_help.py` (пути внутри скриптов — абсолютные, поправьте под своё окружение).

PDF памятки получен из `Быстрый_старт.html` через headless Chrome:

```
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-pdf-header-footer \
  --print-to-pdf=Быстрый_старт.pdf "file://$PWD/Быстрый_старт.html"
```
