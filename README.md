# Документация на панель управления DC2 (гребной тренажёр Dante)

Составлено по видеообзору `media/VID_20261021_175126.mp4` (24 мин), фотографиям из `media/` и исходному коду прошивки `../njord/dc2-firmware` (версия 0.6.10).

| Файл | Что это |
|---|---|
| `Руководство_пользователя_DC2.md` | Полное руководство пользователя (17 разделов, иллюстрации из `images/`). Готово для конвертации в DOCX штатным `md_to_docx_converter.py` |
| `Быстрый_старт.html` / `Быстрый_старт.pdf` | Памятка-инфографика на одну страницу A4 |
| `Интерактивная_справка.html` | Автономный интерактивный справочник: «живой» макет панели с кликабельными зонами, карта экранов, пошаговые сценарии, поиск, ссылки на фрагменты видео |
| `images/screens/*.jpg` | 26 выровненных скриншотов экранов (600×1024): 11 статичных экранов вырезаны из фотографий `media/IMG_*.jpg`, остальные (тренировка, отдых, финиш, всплывающие окна) — из видео |
| `images/annotated/active_workout.jpg` | Экран тренировки с пронумерованными выносками |
| `images/ui/*.jpg` | Наборные иллюстрации элементов интерфейса (кнопки, стрелки, переключатели) для раздела 4 руководства, собираются `tools/crop_ui.py` |
| `transcripts/*.txt` | Расшифровка звука видеообзора с таймкодами |
| `tools/` | Скрипты и данные разметки, которыми всё это собрано |

Интерактивная справка открывается в любом браузере двойным щелчком. Ссылки «Фрагмент видео» работают, если файл лежит рядом с папкой `media/`.
Прямые ссылки: `Интерактивная_справка.html#options` (экран), `?view=map` (карта), `?tour=0` (сценарий).

## Репозиторий

Видеофайлы `media/*.mp4` (2,9 ГБ) в git не включены (см. `.gitignore`): в репозитории хранятся фотографии, расшифровки и вырезанные скриншоты. Чтобы пересобрать скриншоты или работали ссылки на фрагменты видео, скопируйте исходные ролики в `media/` вручную.
