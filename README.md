# Документация на панель управления DC2 гребного тренажёра Dante

Пользовательская документация на сенсорную панель управления (дисплейный модуль DC2) гребного тренажёра Dante.
Описание соответствует прошивке **0.6.10**; версия документов **1.1 (28.10.2026)**.

- [Руководство пользователя (PDF)](https://rustemnasyrov.github.io/dante-rowing-machine-manual/dist/Руководство_пользователя_DC2.pdf)
- [Быстрый старт (PDF)](https://rustemnasyrov.github.io/dante-rowing-machine-manual/dist/Быстрый_старт.pdf)
- [Быстрый старт (веб)](https://rustemnasyrov.github.io/dante-rowing-machine-manual/dist/Быстрый_старт.html)

## Готовые документы

Все итоговые файлы лежат в папке [`dist/`](dist/):

| Документ | Файл | Что это |
|---|---|---|
| Руководство пользователя | [`Руководство_пользователя_DC2.pdf`](dist/Руководство_пользователя_DC2.pdf) | Полное руководство, 40 страниц A4: 17 разделов, 4 приложения, иллюстрации всех экранов, оглавление и закладки |
| Быстрый старт | [`Быстрый_старт.pdf`](dist/Быстрый_старт.pdf) | Памятка-инфографика на одну страницу A4 для печати |
| Быстрый старт (веб) | [`Быстрый_старт.html`](dist/Быстрый_старт.html) | Та же памятка в виде автономной веб-страницы |
| Интерактивная справка | [`Интерактивная_справка.html`](dist/Интерактивная_справка.html) | «Живой» макет панели: щёлкайте по элементам экрана, чтобы переходить между окнами и читать описание каждой зоны. Карта экранов, пошаговые сценарии, поиск |

Файлы автономны: картинки встроены внутрь, подключение к интернету не нужно.
В самом репозитории GitHub показывает только PDF; HTML-файлы открывайте по ссылкам сайта выше или скачайте их и откройте в любом браузере.

Прямые ссылки внутри интерактивной справки: `Интерактивная_справка.html#options` (открыть экран), `?view=map` (карта экранов), `?tour=0` (сценарий).

## Исходники

| Путь | Содержимое |
|---|---|

| `media/` | Фотографии панели. Видеообзор (2,9 ГБ) в репозиторий не входит, см. `.gitignore` |

Описания поведения панели сверены с исходным кодом прошивки `dc2-firmware` (Rust, ESP32-S3 + дисплей DWIN DGUS).

## Как пересобрать

Нужны `pandoc`, Google Chrome и Python 3 с пакетами `pymupdf` и `pillow`.

```
python3 tools/build_dist.py
```

Скрипт собирает все четыре файла в `dist/`: встраивает картинки в памятку и печатает её в PDF, собирает интерактивную справку из `tools/hotspots.json`, `tools/tours.json` и `tools/help_template.html`, конвертирует руководство в PDF (обложка, нумерация страниц, оглавление с номерами страниц, закладки).

Чтобы поправить текст: руководство — в `Руководство_пользователя_DC2.md`, памятку — в `Быстрый_старт.html`, описание зоны интерактивной справки — в `tools/hotspots.json`. После правки запустите сборку заново.
